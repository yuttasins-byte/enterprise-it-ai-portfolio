# Professional Learning & Continuous Development

> Continuous learning focused on practical infrastructure, security, cloud, automation, and AI architecture.

## Current Learning Strategy

My learning approach uses two passes:

1. **Foundation pass** — understand the service landscape, terminology, architectural concepts, and decision criteria.
2. **Hands-on pass** — build labs, compare architectures, test security controls, monitor workloads, and evaluate cost and operational trade-offs.

The objective is not to collect service names or badges. It is to improve architecture and operational decision making.

## Architecture Mapping

A key part of the learning process is comparing architectural concepts rather than assuming services are identical across vendors.

| Architecture Area | AWS | Microsoft Azure |
|---|---|---|
| Virtual compute | Amazon EC2 | Azure Virtual Machines |
| Virtual network | Amazon VPC | Azure Virtual Network |
| Object storage | Amazon S3 | Azure Blob Storage |
| Serverless functions | AWS Lambda | Azure Functions |
| DNS | Amazon Route 53 | Azure DNS |
| Dedicated hybrid connectivity | AWS Direct Connect | Azure ExpressRoute |
| Monitoring | Amazon CloudWatch | Azure Monitor |
| Secrets / keys | AWS Secrets Manager / KMS | Azure Key Vault |

These mappings are learning aids only; architecture and feature sets are evaluated individually rather than treated as exact one-to-one equivalents.
